## The fortune

> You will meet the bug you ignored, wearing the face of a customer.

One original line of fortune-cookie wisdom for a software developer,
66 characters. The bug you chose to ignore does not stay ignored — it
comes back to you, only now it arrives as a customer complaint, wearing
a human face.

## How it works

`main.ts` (Node 22+) writes the fortune to `/output/entry.txt`, where
the bounty gate scorer checks it is 1–120 characters of UTF-8 text.

```sh
node main.ts
cat /output/entry.txt
```
